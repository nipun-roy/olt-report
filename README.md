# ⚡ OneSky OLT Report Generator

একটি সহজ ও সুপার-ফাস্ট **OLT অপটিক্যাল রিপোর্ট জেনারেটর**। আপনি শুধু OLT থেকে ডাটা কপি করে পেস্ট করবেন, আর সাথে সাথেই রেডিমেড রিপোর্ট পেয়ে যাবেন!

---

## 🌟 এই সিস্টেমে যা যা রয়েছে:

1. **📋 শুধু OLT ডাটা পেস্ট করুন — ইনস্ট্যান্ট রিপোর্ট রেডি**:
   - BDCOM, VSOL, Huawei, ZTE, CDATA বা যেকোনো ব্র্যান্ডের OLT টার্মিনাল লগ পেস্ট বা ফাইল আপলোড করুন।
   - ১ ক্লিকে সব ONU-র RX Power, Port, MAC Address ও Distance ক্যালকুলেট করে রিপোর্ট তৈরি হয়ে যাবে।

2. **🚨 হাই লস (High dB Loss) ফোকাস**:
   - $\ge 24\text{ dBm}$ (বা আপনার পছন্দমতো থ্রেশহোল্ড) লসের ONU-গুলো স্বয়ংক্রিয়ভাবে লাল ব্যাজে হাইলাইট করা থাকে।
   - ১ ক্লিকে **WhatsApp / Telegram রিপোর্ট কপি** করার অপশন (যা ফিল্ড টেকনিশিয়ানদের সরাসরি পাঠানো যায়)।
   - ১ ক্লিকে **Microsoft Excel (.CSV)** ফরম্যাটে ডাউনলোড।

3. **📑 সকল তৈরি করা রিপোর্ট থাকবে এক জায়গায় (Central Hub)**:
   - আপনি অতীতে বা বর্তমানে যতগুলো OLT-র ডাটা দিয়ে রিপোর্ট তৈরি করবেন, সবগুলো রিপোর্ট তারিখ ও সময় অনুযায়ী সুন্দরভাবে এক জায়গায় সংরক্ষিত থাকবে।
   - যেকোনো রিপোর্টে ক্লিক করলেই সাথে সাথে সেটির সম্পূর্ণ ডাটা ও ফিল্টার চলে আসবে।

4. **🗑️ এক ক্লিকে সব ডাটা ডিলিট (Delete All Data)**:
   - কাজ শেষ হয়ে গেলে বা পুরাতন ডাটা ক্লিয়ার করতে চাইলে উপরের **"একবারে সব ডিলিট"** বাটনে ক্লিক করলেই এক ক্লিকে সব রিপোর্ট ডাটাবেস থেকে মুছে যাবে।

5. **🚫 বাড়তি কোনো অপ্রয়োজনীয় জটিলতা নেই**:
   - কোনো টিকেট সেটআপ বা জটিল কাস্টমার ফর্মের ঝামেলা নেই। শুধুই OLT ডাটা ইনপুট এবং রেডি রিপোর্ট!

## 🚀 কীভাবে চালু করবেন (Run Instructions)

```bash
cd "c:\Users\HP\Desktop\OneSkyNote\OLT PROJECT\olt-manager"
npm run dev
```

ব্রাউজারে ওপেন করুন: **[http://localhost:3000](http://localhost:3000)**
