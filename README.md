# ⚡ OneSky OLT Report & Quick SMS Assistant

একটি আধুনিক, সুপার-ফাস্ট **OLT অপটিক্যাল রিপোর্ট জেনারেটর** এবং **Quick SMS / Snippet Manager** ড্যাশবোর্ড।

---

## 🌟 প্রধান ফিচারসমূহ:

### ১. ⚡ OLT অপটিক্যাল রিপোর্ট জেনারেটর (`/`)
- **ইনস্ট্যান্ট রিপোর্ট:** BDCOM, VSOL, Huawei, ZTE, CDATA বা যেকোনো ব্র্যান্ডের OLT টার্মিনাল লগ পেস্ট বা ফাইল আপলোড করুন — সাথে সাথে রিপোর্ট রেডি।
- **হাই লস হাইলাইটার:** $\ge 24\text{ dBm}$ খারাপ সিগন্যালের ONU-গুলো লাল ব্যাজে আলাদা করা।
- **১-ক্লিকে WhatsApp রিপোর্ট কপি:** টেকনিশিয়ানদের কাছে পাঠানোর রেডিমেড ফরম্যাট।
- **Excel (.CSV) এক্সপোর্ট ও প্রিন্ট সুবিধা।**
- **সকল রিপোর্ট এক জায়গায়:** সকল তৈরি করা রিপোর্ট সংরক্ষিত থাকে এবং ১ ক্লিকে সব ডাটা ডিলিট করার সুবিধা রয়েছে।

### ২. 💬 Quick SMS / Snippet Manager (`/sms`)
- **১-ক্লিকে কপি (1-Click Copy with Toast):** বাটনে ক্লিক করলেই ক্লিপবোর্ডে কপি হবে এবং চমৎকার টোস্ট নোটিফিকেশন আসবে।
- **ডাইনামিক ভেরিয়েবল (Dynamic Placeholders):** টেক্সটে `{name}`, `{amount}`, `{trx_id}`, `{due_date}`, `{area}`, `{onu_id}` থাকলে কার্ডে সরাসরি ইনপুট বক্স চলে আসবে। আপনি টাইপ করবেন আর লাইভ মেসেজে ভ্যালুগুলো বসে সাথে সাথে কপি করার জন্য রেডি হয়ে যাবে!
- **ক্যাটাগরি ও ট্যাগ ফিল্টারিং:** Payment, Billing, Support, Maintenance Alert, New Customer ইত্যাদি।
- **ইন্সট্যান্ট সার্চ (Ctrl + K):** কিবোর্ডে `Ctrl + K` চেপে চোখের পলকে যেকোনো মেসেজ সার্চ ও ফিল্টার করুন।
- **পিন ও ফেভারিট:** প্রয়োজনীয় মেসেজগুলো সবার উপরে পিন (PIN) করে রাখার সুবিধা।
- **ব্যবহার কাউন্টার:** কোন মেসেজটি কতবার কপি হয়েছে তা স্বয়ংক্রিয়ভাবে ট্র্যাক হয়।

## 🚀 কীভাবে চালু করবেন (Run Instructions)

### সহজ পদ্ধতি:
প্রোজেক্ট ফোল্ডারে থাকা **`run-dev.bat`** ফাইলে ডাবল ক্লিক করুন!

### অথবা ম্যানুয়ালি টার্মিনালে:
```bash
npm run dev
```

ব্রাউজারে ওপেন করুন:
- **OLT Report:** [http://localhost:3000](http://localhost:3000)
- **Quick SMS Manager:** [http://localhost:3000/sms](http://localhost:3000/sms)
